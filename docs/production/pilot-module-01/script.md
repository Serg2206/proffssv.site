# Сценарий пилотного модуля: SSVproff® Module 1.1
## Тема: Хирургическая анатомия желудка и лимфоотток
**Хронометраж:** 20 минут
**Формат:** Lecture + 3D Visualization + Interactive Quiz

---

### 00:00 – 01:30 | Вступление (Intro)
*   **Визуал:** Заставка SSVproff® (логотип, эпиграф), переход в студию.
*   **Спикер:** Профессор в операционной форме (или деловом костюме).
*   **Ключевые тезисы:**
    *   "Анатомия — это карта, без которой хирург слеп."
    *   Обзор целей урока: сосудистые вариации, фасциальные футляры, классификация лимфоузлов по JGCA.
*   **Графика:** Lower Thirds (имя спикера, регалии).

### 01:30 – 06:00 | Блок 1: Артериальное кровоснабжение и вариации
*   **Визуал:** Сплит-экран. Слева — спикер, справа — 3D-модель чревного ствола.
*   **Контент:**
    *   Классическая триада (левая желудочная, общая печеночная, селезеночная).
    *   **Critical Point:** Вариации правой печеночной артерии (a. hepatica dextra abberans) из a. mesenterica superior. Риск повреждения при расширенной лимфодиссекции D2.
    *   Демонстрация на 3D-модели: вращение, зум на зону риска.
*   **Инсерт:** Видео реальной интраоперационной ситуации (лапароскопия), где видна пульсация аберрантной артерии.

### 06:00 – 11:00 | Блок 2: Венозный отток и портальная система
*   **Визуал:** Полноэкранная анимация с наложением схем.
*   **Контент:**
    *   Венечная вена (v. coronaria ventriculi) — путь метастазирования в печень.
    *   Связь с поджелудочной железой (головка).
    *   Техника мобилизации двенадцатиперстной кишки (Kocher maneuver) для доступа к забрюшинным узлам.
*   **Red Flag:** Предупреждение о риске кровотечения из v. mesenterica superior при неаккуратной диссекции.

### 11:00 – 16:00 | Блок 3: Лимфатическая система (JGCA Classification)
*   **Визуал:** Интерактивная схема желудка (рисунок от руки поверх экрана или анимированный атлас).
*   **Контент:**
    *   Группы лимфоузлов №1–№16.
    *   Концепция "станций" (Station 1, 2, 3).
    *   Показания для D1, D1+, D2 лимфодиссекции.
    *   **Case Study:** КТ-скан пациента с опухоью тела желудка. Разбор зон метастазирования.
*   **Интерактив:** Пауза для вопроса аудитории: "Где граница резекции при опухоли антрального отдела?"

### 16:00 – 18:30 | Блок 4: Фасциальные плоскости и принципы бесконтактности
*   **Визуал:** Макросъемка препарированного препарата (или качественная 3D-симуляция слоев).
*   **Контент:**
    *   Фасция Тольдта.
    *   Принцип "Holy Plane" в онкохирургии желудка.
    *   Важность удаления жировой клетчатки единым блоком (en bloc resection).

### 18:30 – 20:00 | Заключение и Тест
*   **Визуал:** Возврат в студию.
*   **Call to Action:**
    *   "Скачайте чек-лист анатомических ориентиров."
    *   "Пройдите тест для допуска к следующему модулю."
*   **Финал:** Логотип SSVproff®, контакты для консультаций.

---

### Технические требования к съемке:
1.  **Камеры:** 2 шт. (Основная 4K + Крупный план рук/схем).
2.  **Свет:** Схема "Rembrandt" для лица, контровой свет для отделения от фона.
3.  **Звук:** Петличный микрофон (Sennheiser G4) + резервный рекордер.
4.  **Фон:** Студия с медицинским уклоном (мониторы, манекен, стеллаж с книгами/атласами).
5.  **Реквизит:** Анатомический препарат желудка (влажный препарат в банке) или высокодетализированная пластиковая модель.

### Пост-продакшн:
*   Цветокоррекция: Стиль "Medical Clean" (холодные тона, высокая четкость).
*   Графика: Внедрение интерактивных точек (H5P) поверх видео для проверки знаний.
*   Субтитры: Русские (полные) + Английские (для международной версии).
