# Чек-лист подготовки к съемке пилотного модуля (Module 1.1)

## 📅 Этап 1: Пре-продакшн (За 3 дня до съемки)

### Локация и Студия
- [ ] Бронирование студии (минимум 4 часа).
- [ ] Проверка фонового оформления (книги, манекен, мониторы).
- [ ] Тест розеток и электрической сети (нагрузка на свет).
- [ ] Проверка кондиционирования (тишина работы).

### Оборудование
- [ ] Камеры: 2x Sony A7S III / FX3 (или аналог 4K).
- [ ] Объективы: 24-70mm f/2.8 (общий), 50mm/85mm f/1.8 (портрет/детали).
- [ ] Свет: Key Light (Softbox 90cm), Fill Light, Rim Light (RGB для фона).
- [ ] Звук: Sennheiser G4 (петличка) + Zoom H6 (резерв).
- [ ] Штативы: Тяжелые видео-штативы с гидравлической головой.
- [ ] Монитор режиссера (для контроля картинки в реальном времени).
- [ ] Телепромптер (если требуется точный текст, но лучше импровизация эксперта).

### Контент и Реквизит
- [ ] Распечатка сценария (крупный шрифт, тайминги).
- [ ] Презентация для мониторов (слайды по тайм-кодам).
- [ ] Анатомический препарат/модель желудка (проверить чистоту, этикетки).
- [ ] Хирургические инструменты для демонстрации (зажимы, ножницы — новые, блестящие).
- [ ] Форма спикера (чистый халат/костюм, бейдж SSVproff®).

### Команда
- [ ] Спикер (Профессор).
- [ ] Режиссер/Оператор.
- [ ] Звукорежиссер.
- [ ] Ассистент (для подачи реквизита и света).

---

## 🎬 Этап 2: День съемки (Run of Show)

### 09:00 – 10:00 | Монтаж и Саундчек
- [ ] Установка камер и света.
- [ ] Настройка баланса белого (5600K).
- [ ] Проверка уровней звука (цель: -12dB пики, отсутствие шумов).
- [ ] Запись "хлопушки" (синхронизация).

### 10:00 – 10:30 | Репетиция
- [ ] Проход по сценарию без записи.
- [ ] Проверка зон видимости графики (где будет картинка поверх видео).
- [ ] Корректировка посадки спикера.

### 10:30 – 12:30 | Съемка Блоков (Takes)
- [ ] **Take 1:** Вступление (00:00–01:30). *Повторить 2 раза для выбора.*
- [ ] **Take 2:** Блок 1 (Артерии). Работа с 3D-монитором.
- [ ] **Take 3:** Блок 2 (Вены).
- [ ] **Take 4:** Блок 3 (Лимфоузлы). Работа с планшетом/КТ-снимками.
- [ ] **Take 5:** Блок 4 (Фасции). Макро-съемка инструментов/препарата.
- [ ] **Take 6:** Заключение.

### 12:30 – 13:00 | Перерыв

### 13:00 – 14:00 | B-Roll (Дополнительные планы)
- [ ] Крупные планы рук хирурга (жесты, указка).
- [ ] Детали анатомической модели (зум на сосуды).
- [ ] Эмоциональные перебивки (задумчивость, уверенность).
- [ ] Логотип SSVproff® на фоне.

### 14:00 – 14:30 | Упаковка
- [ ] Проверка всех файлов на картах памяти (дублирование).
- [ ] Разбор оборудования.

---

## 💻 Этап 3: Пост-продакшн (Сразу после съемки)

### Организация данных
- [ ] Копирование материала на RAID-диски (Основная + Копия).
- [ ] Структура папок: `01_Raw`, `02_Audio`, `03_Graphics`, `04_Exports`.
- [ ] Бэкап в облако (AWS S3 / Google Drive).

### Монтаж (Черновик)
- [ ] Синхронизация звука и видео.
- [ ] Сборка "черновой нарезки" (Rough Cut) по сценарию.
- [ ] Отбор лучших дублей.

### Графика и VFX
- [ ] Вставка 3D-анимаций (заказ у моушн-дизайнера или рендер из библиотек).
- [ ] Наложение Lower Thirds (титры).
- [ ] Цветокоррекция (Davinci Resolve).

### Финализация
- [ ] Сведение звука (шумодав, эквалайзер, компрессия).
- [ ] Экспорт мастер-файла (ProRes 422 HQ, 4K).
- [ ] Создание веб-версии (H.264, 1080p, битрейт 15 Mbps).
- [ ] Загрузка на Vimeo Pro (настройка приватности: Domain lock).

---

## ✅ Критерии приемки пилота
- [ ] Картинка четкая, нет "мыла".
- [ ] Звук чистый, нет эха и посторонних шумов.
- [ ] Тайминг соблюден (20 +/- 1 мин).
- [ ] Графика читаема на мобильных устройствах.
- [ ] Спикер выглядит уверенно, взгляд в камеру.
- [ ] Логотип SSVproff® присутствует в начале и конце.

*Ответственный за подписание акта приемки: Продюсер курса.*
