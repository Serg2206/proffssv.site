# План запуска пилотного модуля SSVproff® (Неделя 1)

## 🎯 Цель недели
Развернуть тестовое окружение LMS и полностью отснять материал для Модуля 1.1 ("Хирургическая анатомия").

---

## 📅 День 1: Инфраструктура (LMS Setup)

**Задачи:**
1.  **Подготовка сервера:**
    *   Аренда VPS (рекомендация: Hetzner CPX31 или DigitalOcean Droplet 4GB RAM).
    *   Установка Docker & Docker Compose.
    *   Настройка домена `lms.ssvproff.com` (или локального туннеля ngrok для тестов).
2.  **Развертывание контейнеров:**
    *   Клонирование репозитория с конфигом.
    *   Запуск `docker-compose up -d`.
    *   Проверка доступности WordPress (порт 8080) и phpMyAdmin (порт 8081).
3.  **Базовая настройка WordPress:**
    *   Установка языка, часового пояса.
    *   Установка плагина **LearnDash LMS** (загрузка trial-версии или лицензии).
    *   Установка темы **Kadence WP**.
    *   Настройка постоянных ссылок (Post name).

**Результат дня:** Работающий сайт на WordPress с установленным плагином LMS. Доступен по ссылке.

---

## 📅 День 2: Наполнение и Тестирование LMS

**Задачи:**
1.  **Структура курса:**
    *   Создание курса "Gastric Adenocarcinoma 2026".
    *   Создание секции "Module 1: Fundamentals".
    *   Создание урока "1.1 Surgical Anatomy".
2.  **Настройка доступа:**
    *   Включение режима "Drip-feed" (по расписанию).
    *   Создание тестового пользователя "Student_Test".
    *   Настройка квиза (Quiz) с проходным баллом 80%.
3.  **Интеграция видео-плеера:**
    *   Регистрация аккаунта Vimeo Pro.
    *   Настройка Domain Privacy (разрешить только домен курса).
    *   Тестовая загрузка заглушки (placeholder video).
4.  **Установка плагина H5P:**
    *   Создание интерактивного элемента "Image Hotspots" (Анатомия желудка).

**Результат дня:** Полностью настроенная структура курса, готовая к приему контента. Тестовый пользователь может войти и видеть "скелет" урока.
