## Меры безопасности

### ✅ Реализовано
1. **Криптографически стойкие пароли** — сгенерированы через `openssl rand -base64 32` (256 бит)
2. **Debug mode отключён** — `WORDPRESS_DEBUG=0` (production-ready)
3. **Файл .env исключён из Git** — добавлен в `.gitignore`
4. **Резервная копия создана** — `/docs/lms/credentials/.env.production.backup`
5. **Бэкапы исключены из Git** — паттерн `*.backup` добавлен в `.gitignore`

### ⚠️ Требуется выполнить
1. **Сохранить пароли в менеджере паролей** (1Password, Bitwarden, KeePass)
2. **Ограничить доступ к файлу** на сервере: `chmod 600 .env`
3. **Настроить ротацию паролей** каждые 90 дней
4. **Включить 2FA** для всех администраторов после развёртывания

## Инструкция по развёртыванию

### Локальное тестирование
```bash
cd docs/lms
docker-compose up -d
```

Доступ:
- WordPress: http://localhost:8080
- phpMyAdmin: http://localhost:8081

### Production-развёртывание
1. Скопировать `.env` на сервер в защищённую директорию
2. Установить права: `chmod 600 .env`
3. Запустить Docker-контейнеры
4. Немедленно сменить пароли по умолчанию при первом входе
5. Настроить брандмауэр (доступ только с доверенных IP)
