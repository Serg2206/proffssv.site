## 2. Итоговое решение: LearnDash + WordPress

**Обоснование выбора:**
Для проекта уровня **SSVproff®** критически важно владение контентом и возможность кастомизации под медицинскую специфику (сложные схемы, интерактивные тесты, защита от скачивания).
*   **LearnDash** — лидер рынка для профессиональных курсов (используется университетами и топ-тренерами).
*   Позволяет реализовать модель "Drip Content" (постепенное открытие уроков).
*   Интегрируется с **H5P** для создания интерактивных медицинских схем.
*   Полный контроль над брендингом без логотипов платформы-агрегатора.

## 3. Архитектура тестового окружения

### Стек технологий:
*   **CMS:** WordPress 6.5+
*   **LMS Plugin:** LearnDash LMS 4.x
*   **Theme:** Kadence WP (легкая, быстрая, совместима с LearnDash)
*   **Video Hosting:** Vimeo Pro (скрытый плеер, доменная привязка ssvproff.com)
*   **Interactive:** H5P Plugin
*   **Server:** Docker (Nginx, PHP 8.2, MariaDB)

### Структура курса в LMS:
1.  **Course:** SSVproff® Gastric Cancer 2026
2.  **Section:** Module 1. Fundamentals & Anatomy
3.  **Lesson:** 1.1 Surgical Anatomy & Lymphatic Drainage
4.  **Topic:** Video Lecture (20 min)
5.  **Quiz:** Anatomy Checkpoint (Pass rate 80%)
6.  **Assignment:** Upload CT scan analysis

## 4. План развертывания (Day 1-3)

1.  **День 1:** Поднятие Docker-контейнера, установка WP, настройка SSL.
2.  **День 2:** Установка LearnDash, настройка тем, загрузка демо-контента.
3.  **День 3:** Настройка Vimeo, интеграция первого видео, тестирование доступа.

---
*Рекомендация: Для начала использовать локальный Docker-стенд для отработки пилота, затем перенос на выделенный VPS (DigitalOcean/Hetzner) для продакшена.*
