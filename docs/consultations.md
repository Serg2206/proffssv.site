# Консультации

Информация о консультациях и возможности получения профессиональной помощи.

## О консультациях

Профессиональные консультации по вопросам хирургии и медицинских исследований.

### Форматы консультаций

- **Онлайн-консультации** — удалённое обсуждение вопросов
- **Очные встречи** — при возможности личной встречи
- **Групповые сессии** — для образовательных целей

## Как записаться

Для записи на консультацию:

1. Оставьте заявку через форму связи
2. Укажите тему и формат консультации
3. Согласуйте удобное время

## Важно

> Консультации носят информационный характер и не заменяют очный визит к врачу.
