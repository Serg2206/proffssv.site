## 3. Детальный План Визуализации по Модулям

### Модуль 1: Эпидемиология и Молекулярная Биология
*   **Визуал 1.1 (Инфографика)**: Карта мира с тепловой картой заболеваемости (Япония/Корея vs Европа/США).
*   **Визуал 1.2 (Схема)**: "Молекулярный паспорт опухоли" (TCGA классификация: EBV, MSI, Genomic Stable, Chromosomal Instability).
    *   *Формат*: Интерактивная схема, где при клике раскрываются мишени для таргетной терапии.
*   **Визуал 1.3 (Скан)**: Примеры иммуногистохимии (HER2, PD-L1, E-cadherin) с подписями профессора.

### Модуль 2: Преоперационная Диагностика и Стадирование
*   **Визуал 2.1 (Видео-луп)**: Динамическая КТ с пероральным контрастированием. Показать разницу между T3 и T4a.
*   **Визуал 2.2 (Алгоритм)**: Flowchart "Диагностическая лапароскопия: Когда она обязательна?".
    *   *Точки решения*: cT3/4, диффузный тип, подозрение на канцероматоз.
*   **Визуал 2.3 (Фото)**: Эндоскопические признаки раннего рака (0-IIa, 0-IIc) по японской классификации.

### Модуль 3: Хирургическая Анатомия (Золотой Стандарт)
*   **Визуал 3.1 (3D Рендер)**: Слоистая анатомия сальниковых сумок. Отключение слоев (skin -> fat -> muscle -> vessels).
*   **Визуал 3.2 (Схема)**: Лимфоколлекторы D1, D2, D3. Цветовое кодирование станций (№1-16).
*   **Визуал 3.3 (Видео-наложение)**: Реальное лапароскопическое видео + наложенная 3D-модель сосудов (Augmented Reality style).

### Модуль 4: Техника Гастрэктомии (Step-by-Step)
*   **Визуал 4.1 (Серия фото)**: "Критические моменты операции" (Critical View of Safety).
    1.  Вход в сальниковую сумку.
    2.  Выделение a. gastrica sinistra у ствола чревного сплетения.
    3.  Лимфодиссекция вдоль a. hepatica communis.
*   **Визуал 4.2 (Видео-таймлапс)**: Полная гастрэктомия за 3 минуты с субтитрами-комментариями.
*   **Визуал 4.3 (Схема)**: Варианты реконструкции (Ру-анастомоз, Еюностома по Брауну).

### Модуль 5: Осложнения и Их Профилактика
*   **Визуал 5.1 (Инфографика)**: "Карта рисков" — где чаще всего возникают несостоятельности швов.
*   **Визуал 5.2 (Видео)**: Техника интраоперационной проверки герметичности анастомоза (тест с метиленовым синим/воздухом).
*   **Визуал 5.3 (Кейс)**: Рентген/КТ пациента с осложнением -> Тактика ведения -> Результат.

## 5. Требования к Видеоконтенту

1.  **Разрешение**: Минимум 1080p, предпочтительно 4K.
2.  **Стабилизация**: Использование стабилизаторов или пост-обработка (Warp Stabilizer).
3.  **Освещение**: Холодный свет (5600K), отсутствие теней в операционном поле.
4.  **Монтаж**:
    *   Удаление "мертвого времени" (коагуляция, промывание).
    *   Ускорение рутинных моментов (x4-x8 speed).
    *   Замедление критических этапов (x0.5 slow-mo) с зумом.
5.  **Аудио**: Чистый голос лектора поверх шума аспиратора (шумоподавление AI).

## 6. Интерактивные Элементы (LMS Integration)

*   **Hotspot Images**: Фото операции, где курсант должен нажать на правильную артерию.
*   **Quiz Video**: Видео останавливается на критическом моменте ("Что делать дальше?"), выбор варианта ответа продолжает видео.
*   **3D Viewer**: Встроенный в браузер вьюер для вращения модели желудка и лимфоузлов.
